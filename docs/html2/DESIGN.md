# DESIGN.md — 헬스케어 앱 공통 디자인 가이드

> 본 문서는 모바일 앱(시니어·자녀)과 PC 웹(와치 관리자·의료진·운영자)에 공통으로 적용되는 디자인 기준이다.

---

## 1. 디자인 원칙

| 원칙   | 설명                                                                          |
| ------ | ----------------------------------------------------------------------------- |
| 명확성 | 60대 이상 시니어가 한눈에 이해할 수 있도록 정보를 단순하게 표현한다           |
| 접근성 | 시력·청력 저하를 고려해 고대비·대형 텍스트·TTS를 기본 지원한다                |
| 일관성 | 앱과 PC 웹에서 동일한 색상·컴포넌트·용어를 사용한다                           |
| 안전성 | SOS·긴급 기능은 항상 최상위에 노출하고, 실수로 누르지 않도록 확인 단계를 둔다 |

## 2. 색상 시스템

### 2.1 주요 색상 (Brand Colors)

| 용도         | 이름      | HEX       | 사용처                 |

| Neutral      | 슬레이트  | `#546E7A` | 보조 텍스트, 비활성    |

## 3. 타이포그래피

### 3.1 폰트

- **기본 폰트**: Noto Sans KR (한국어 최적화, 가독성 우수)
- **숫자·데이터**: Roboto (헬스 수치 표현에 적합)
- **웹폰트 로드 순서**: Noto Sans KR → Roboto → system-ui

### 3.2 글자 크기 체계

| 레벨    | 용도                  | 간단보기        | 자세히 보기     |
| ------- | --------------------- | --------------- | --------------- |
| Display | 핵심 수치 (심박수 등) | 48px / Bold     | 36px / Bold     |
| H1      | 페이지 제목           | 28px / Bold     | 24px / Bold     |
| H2      | 섹션 제목             | 22px / SemiBold | 18px / SemiBold |
| H3      | 카드 제목             | 18px / SemiBold | 16px / Medium   |
| Body    | 본문                  | 18px / Regular  | 15px / Regular  |
| Caption | 보조 텍스트           | 15px / Regular  | 13px / Regular  |
| Label   | 버튼·태그             | 16px / SemiBold | 14px / SemiBold |

### 3.3 행간·자간

| 항목                  | 값                       |
| --------------------- | ------------------------ |
| 행간 (line-height)    | 1.6 (본문), 1.3 (제목)   |
| 자간 (letter-spacing) | -0.01em (제목), 0 (본문) |

## 5. 컴포넌트

### 5.1 버튼

| 종류      | 용도                   | 최소 높이 | 스타일                                        |
| --------- | ---------------------- | --------- | --------------------------------------------- |
| Primary   | 주요 액션 (저장, 확인) | 56px      | 배경 `#2B7FE0`, 텍스트 흰색, radius 12px      |
| Secondary | 보조 액션 (취소, 뒤로) | 56px      | 테두리 `#2B7FE0`, 텍스트 `#2B7FE0`, 배경 투명 |
| Danger    | 삭제, SOS              | 56px      | 배경 `#E53935`, 텍스트 흰색                   |
| Ghost     | 링크형 액션            | 44px      | 배경 없음, 텍스트 `#2B7FE0`                   |
| Icon      | 아이콘 단독 버튼       | 48×48px   | 원형 또는 정사각, 터치 영역 최소 48px         |

- 간단보기 모드에서는 모든 버튼 높이를 +8px 추가 적용한다
- 버튼 간 최소 간격: 12px 이상

### 5.2 카드

```
┌─────────────────────────────┐
│  아이콘  제목               │  ← 카드 헤더 (패딩 16px)
│─────────────────────────────│
│  핵심 수치 / 내용           │  ← 카드 바디 (패딩 16px)
│  보조 설명                  │
│─────────────────────────────│
│  [액션 버튼]                │  ← 카드 푸터 (선택)
└─────────────────────────────┘
```

- border-radius: 16px
- box-shadow: `0 2px 12px rgba(0,0,0,0.08)`
- 배경: `#FFFFFF`

### 5.3 건강 수치 카드 (Health Metric Card)

```
┌─────────────────────────────┐
│  🫀 심박수          [토글▼] │  ← 또래 평균 / 어제와 비교 토글
│─────────────────────────────│
│        72 bpm               │  ← Display 폰트 (48px)
│  ● 정상  또래 평균 71 bpm   │  ← 비교 기준값
│  ────────●──────────        │  ← 범위 바 (min~max)
└─────────────────────────────┘
```

- 상태 색상: 정상 `#34C4A0` / 주의 `#F5A623` / 위험 `#E53935`
- 토글은 카드 우측 상단, 드롭다운 또는 슬라이드 스위치 형태

### 5.4 SOS 버튼

```
┌──────────────┐
│              │
│     SOS      │  ← 80×80px 원형, 배경 #E53935, 텍스트 흰색 Bold
│              │
└──────────────┘
```

- 홈화면 하단 고정 (FAB 방식)
- 누른 후 3초 카운트다운 → 취소 가능 → 이후 자동 발송
- 주변 여백 최소 20px 확보 (실수 터치 방지)

### 5.5 토글 스위치

- 너비: 56px / 높이: 30px
- ON 색상: `#2B7FE0` / OFF 색상: `#B0BEC5`
- 레이블 텍스트는 토글 좌측에 위치

### 5.6 탭 네비게이션 (앱 하단)

| 탭     | 아이콘  | 간단보기 노출 |
| ------ | ------- | ------------- |
| 홈     | 집 모양 | ✅             |
| 건강   | 심박    | ✅             |
| 복약   | 알약    | ✅             |
| 일정   | 캘린더  | ✅             |
| 더보기 | 햄버거  | ✅             |

- 탭 높이: 64px (간단보기 72px)
- 활성 탭: Primary 색상 + 텍스트 레이블 표시
- 비활성 탭: `#B0BEC5` + 텍스트 레이블 표시 (시니어 배려)

### 5.7 알림 배지

- 원형, 최소 20×20px
- 배경: `#E53935`, 텍스트 흰색 Bold
- 숫자 99 초과 시 "99+" 표시

### 5.8 입력 폼

- 높이: 52px (간단보기 60px)
- border-radius: 10px
- 포커스 시 border: 2px solid `#2B7FE0`
- 오류 시 border: 2px solid `#E53935` + 오류 메시지 하단 표시 (빨간색)
- 레이블은 입력 필드 위에 위치 (플로팅 레이블 미사용 — 시니어 혼란 방지)

## 6. 아이콘

- **색상**: 텍스트와 동일한 색상 계열 사용

## 10. 접근성 체크리스트

- [ ] 모든 이미지·아이콘에 alt 텍스트 또는 aria-label 제공
- [ ] 색상만으로 상태를 구분하지 않고, 아이콘·텍스트 병행 사용
- [ ] 터치 영역 최소 48×48px 준수
- [ ] 포커스 아웃라인 `2px solid #2B7FE0` 항상 표시 (outline 제거 금지)
- [ ] 명도 대비비 WCAG AA 기준 이상 (텍스트 4.5:1, 대형 텍스트 3:1)
- [ ] TTS 읽기 순서가 시각적 순서와 일치하도록 DOM 구성
