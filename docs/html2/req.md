# 개요

60대 이상 시니어를 위한 헬스케어 서비스로, 2개의 플랫폼으로 구성된다.

| 플랫폼 | 대상 | 주요 역할 |
|--------|------|-----------|
| 모바일 앱 (반응형) | 시니어 (60대+), 자녀/보호자 | 헬스케어 정보 확인·관리, 긴급 대응 |
| PC 웹 | 와치 관리자 / 의료진 / 운영자 | 로그인 권한에 따라 다른 화면 제공 |

PC 웹은 단일 서비스이며, 로그인한 계정의 권한에 따라 아래 3가지 화면으로 분기된다.

| 권한 | 주요 역할 |
|------|-----------|
| 와치 관리자 | 기기 제공·수집 항목 설정·의료진-시니어 연결 |
| 의료진 | 데이터 조회·조언·원격 상담 |
| 운영자 | 계정·권한·시스템 운영 관리 |

# 요구사항

## 1. 보기 모드 (간단보기 / 자세히 보기)

앱은 **간단보기**와 **자세히 보기** 2가지 버전으로 제공하며, 시니어(부모님)와 자녀 모두 언제든 자유롭게 전환할 수 있다.

| 구분 | 간단보기 | 자세히 보기 |
|------|----------|-------------|
| 대상 | IT에 익숙하지 않은 시니어 | IT에 익숙한 시니어·자녀 |
| 홈화면 | 오늘의 건강 요약·복약·SOS 3개 카드 | 전체 건강 지표 대시보드 |
| 글자·버튼 | 대형 (특대 글자, 큰 버튼) | 일반 크기 |
| 제공 정보 | 핵심 수치(심박수·혈압·복약 여부) | 트렌드 그래프·또래 비교·상세 기록 전체 |
| 기본값 | 최초 설치 시 기본 적용 | 사용자가 직접 전환 |

- 전환 버튼은 홈화면 상단에 항상 노출한다
- 자녀가 부모 계정을 대리 관리 중일 때도 모드 전환 가능하다

## 2. 자녀/보호자 대리 케어

- 동일 앱 내에서 계정 전환으로 자녀가 부모 계정을 관리한다 (별도 앱 불필요)
- 자녀 권한 범위: 복약 확인·일정 등록·의료진 상담 요청 가능, 건강 데이터 삭제 불가
- 자녀가 설정을 변경하면 시니어에게 앱 알림으로 자동 통보한다
- 보호자는 최대 3명까지 등록 가능하며, 시니어 본인이 권한 범위를 승인한다

## 3. 긴급 상황 대응 (Critical)

- **SOS 버튼**: 홈화면 고정, 한 번 누르면 등록된 자녀 전원 + 운영자에게 즉시 알림
- **낙상 감지**: 와치 가속도 센서 기반, 감지 시 30초 내 반응 없으면 자동 SOS 발송
- **비정상 활력징후 경보**: 심박수·혈압이 설정 범위 초과 시 자녀·의료진 동시 알림
- 긴급 연락처(자녀·주치의·119)를 앱에서 원터치로 호출 가능

## 4. 알림·리마인더

- 복약 알림: 시간·요일 설정, 미복용 시 자녀에게 2차 알림 발송
- 병원 예약 알림: 예약일 D-3, D-1, 당일 오전 발송
- 건강 검진 주기 알림: 마지막 검진일 기준으로 권장 주기 도래 시 알림
- 운동·활동 독려: 하루 걸음 수 목표 미달 시 오후 알림 (끄기 가능)
- 알림 수신 대상을 시니어 단독 또는 시니어+자녀 동시로 선택 가능

## 5. 복약 관리

- 복용 중인 약 목록 등록 (약 이름·용량·복용 시간)
- 당일 복약 여부 체크 (본인 또는 자녀가 확인 가능)
- 월간 복약 달력 뷰 제공
- 의료진이 처방 변경 시 앱에서 자동 업데이트 알림

## 6. 건강 데이터 관리

- 와치 연동 자동 수집: 심박수, 혈중 산소, 수면 패턴, 걸음 수, 활동량
- 수동 입력: 혈압, 혈당, 체중, 체온 (와치 외 기기 사용자 대응)
- 식사 기록: 간단 분류(정상·과식·소식)로 입력 부담 최소화, 당뇨·고혈압 관리용
- 주간·월간·연간 트렌드 그래프로 변화 추이 시각화

## 7. 건강 데이터 비교 보기 (토글)

헬스케어 정보 화면에서 **또래 평균 비교**와 **어제와 비교** 두 가지 기준을 토글로 전환하며 볼 수 있다.

| 구분 | 또래 평균 비교 | 어제와 비교 |
|------|---------------|-------------|
| 기준 | 동일 성별·5세 단위 연령대·주요 만성질환 유무 | 전일 동일 시간대 측정값 |
| 표시 방식 | **"또래보다 높음 ↑" / "또래보다 낮음 ↓"** 를 크게 표시, 기준값·차이 수치는 부가 정보로 표시 | **"어제보다 높음 ↑" / "어제보다 낮음 ↓"** 를 크게 표시, 어제 수치·차이는 부가 정보로 표시 |
| 활용 목적 | 건강 수준이 또래 대비 어느 위치인지 파악 | 하루 단위 변화 추이 빠르게 확인 |

- 토글은 건강 데이터 화면 상단에 노출하며, 간단보기·자세히 보기 모두에서 사용 가능하다
- 선택한 비교 기준은 앱 재실행 후에도 유지된다
- 또래 평균 비교 기준은 시니어 앱·의료진·자녀 화면 모두에서 동일하게 적용된다
- 어제 측정값이 없는 항목은 "데이터 없음"으로 표시하고 또래 평균 비교로 자동 전환된다

## 8. 스케줄 관리

- 병원 예약, 건강 검진, 운동 일정 등록
- 월간 캘린더 뷰 기본, 일간·주간 전환 가능
- 자녀가 일정을 대신 등록 가능 (등록 시 시니어에게 알림)

## 9. 의료진 소통

- 의료진 → 시니어: 조언·소견 메시지 단방향 전달 (앱 알림 + 자녀 동시 수신 옵션)
- 시니어/자녀 → 의료진: 질문 메시지 전송 가능
- 원격 상담: 의료진이 영상통화 일정을 제안하면 시니어·자녀가 수락/거절
- 의료진이 소견서·리포트를 PDF로 생성해 시니어·자녀에게 공유 가능

## 10. 접근성 (시니어 UX)

- 글자 크기 4단계 조절 (소·중·대·특대)
- 고대비 모드 (흰 배경 + 굵은 검정 글씨)
- 주요 버튼 최소 크기 48px 이상, 핵심 기능은 홈화면에서 2탭 이내 접근
- 음성 읽기 지원 (TTS): 알림 메시지·복약 안내 음성 출력
- 간편 홈화면: 오늘의 건강 요약·복약·SOS 3개 카드만 표시하는 모드

## 11. 개인정보·동의

- 최초 가입 시 의료데이터 수집·활용 동의 (필수/선택 항목 구분)
- 자녀 공유 범위를 시니어 본인이 설정 (전체 공개·요약만·비공개)
- 의료진 공개 범위 설정: 기간별·항목별로 선택 가능
- 동의 내용은 앱 내에서 언제든 변경·철회 가능

## 12. 보안·인증

- 생체인증(지문·얼굴) 우선, 비밀번호 보조 수단으로 사용
- 자녀가 시니어 기기 분실·도난 신고 시 원격 잠금 요청 가능
- 건강 데이터 정기 백업 (주 1회 자동), 기기 변경 시 복원 지원

# 와치 관리자 역할 (PC 웹)

와치 관리자는 **병원·기관 단위**로 운영된다. 각 병원마다 별도의 와치 관리자 계정이 부여되며, 자신의 소속 병원 내 시니어·기기·의료진만 관리할 수 있다. 타 병원 데이터에는 접근 불가.

- **소속 병원 정보 관리**: 병원명·주소·연락처, 소속 의료진 목록 확인·수정
- **시니어 신규 등록**: 새 시니어를 소속 병원에 등록하고 기기 배포
- 와치 기기 배포·회수·재고 현황 관리 (소속 병원 배포분 한정)
- 시니어별 수집 항목 설정 및 기기 연결 상태 모니터링 (소속 시니어 한정)
- 의료진-시니어 매칭 — 소속 병원의 의료진과 시니어 간에만 매칭 가능
- 시니어 건강 데이터 수집 현황 확인 (소속 병원 시니어 한정)

# 운영자 역할 (PC 웹)

- 시니어·자녀·의료진·와치 관리자 계정 승인 및 관리
- 데이터 접근 권한 관리 (역할별 열람 범위 설정)
- 시스템 운영 현황 대시보드 (가입자 수·활성 기기·긴급 이벤트 내역)
- 공지사항·시스템 설정 관리
