## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | (미정) 헬스케어 앱 |
| 대상 | 60대 이상 시니어 + 자녀/보호자 |
| 플랫폼 | 모바일 앱 (반응형) + PC 웹 (단일, 권한별 분기) |
| 핵심 가치 | 시니어의 건강을 가족·의료진이 함께 관리하는 연결 서비스 |

---

## 2. 사용자 역할 정의

| 역할 | 플랫폼 | 주요 목적 |
|------|--------|-----------|
| 시니어 | 모바일 앱 | 내 건강 데이터 확인, 복약·일정 관리 |
| 자녀/보호자 | 모바일 앱 (계정 전환) | 부모 건강 모니터링, 대리 케어 |
| 의료진 | PC 웹 | 환자 데이터 조회, 조언 전달, 원격 상담 |
| 와치 관리자 | PC 웹 | 소속 병원 내 기기 관리, 의료진-시니어 매칭 (병원 단위 계정, 타 병원 접근 불가) |
| 관리자 | PC 웹 | 시스템 최고 권한 — 병원·계정·권한·시스템 설정·운영자 계정 관리 |
| 운영자 | PC 웹 | 일상 서비스 운영 — 대시보드 모니터링·공지사항 관리·계정 조회(읽기 전용) |

> **관리자 vs 운영자 구분**: 관리자는 시스템 구조를 변경할 수 있는 최고 권한자이며, 운영자는 일상 운영 업무(콘텐츠·모니터링)만 담당한다. 운영자는 계정 승인·삭제·권한 변경·병원 등록·시스템 설정 변경이 불가하다.

### 3.5 PC 웹 — 관리자

> 시스템 최고 권한자. 병원 등록·계정 승인·권한 설정·시스템 변경 모두 가능.

| # | 화면명 | 주요 기능 |
|---|--------|-----------|
| A-01 | 대시보드 | 전체 병원 수·가입자 수·활성 기기 수·긴급 이벤트, 역할별 가입자 현황 바 차트, CSV 리포트 다운로드 |
| A-02 | 계정 관리 | 시니어·자녀·의료진·와치 관리자 계정 승인·정지·삭제, 가입 대기 목록, 계정별 신체 정보(키·몸무게·출생년도·성별) 포함 |
| A-03 | 권한 관리 | 탭 UI — [역할별 권한 설정] 기능 ON/OFF 매트릭스 / [건강 데이터 공개 범위] 역할별 항목 열람 범위 설정, 권한 변경 이력 |
| A-04 | 병원·기관 관리 | 병원 등록·수정·비활성화, 와치 관리자 계정 배정, 병원별 현황 |
| A-05 | 시스템 설정 | 알림 설정, 수집 항목 기본값, 긴급 경보 기준값(심박수·혈압 임계치) |
| A-06 | 운영자 관리 | 운영자 계정 생성·비활성화, 업무 범위 지정, 활동 이력 조회 |
| A-07 | 공지사항 관리 | 공지 작성·수정·삭제, 대상 역할 지정, 예약 발송 |
| A-08 | 내 계정 | 프로필 확인·수정, 비밀번호 변경(강도 표시), 최근 활동 이력 |
| A-09 | 또래 평균 관리 | 연령대·성별별 건강 지표 평균값 설정 및 현황 조회 |

#### A-03 권한 관리 탭 구조

| 탭 | 내용 |
|----|------|
| 역할별 권한 설정 | 시니어·자녀·의료진·와치관리자·운영자 역할 × 기능(건강조회·복약·일정 등) ON/OFF 토글 매트릭스. 운영자는 전체 ON 고정. |
| 건강 데이터 공개 범위 | 심박수·혈압·수면·걸음수 등 항목별로 자녀·의료진·와치관리자·운영자에게 전체 공개 / 요약만 / 비공개 설정. |

#### A-04 병원·기관 관리 상세

병원 데이터는 와치 관리자 범위의 최상위 단위다. **관리자만** 병원을 등록·관리할 수 있다.

| 기능 | 설명 |
|------|------|
| 병원 목록 | 병원명·코드·지역·와치 관리자·의료진 수·시니어 수·기기 수·등록일·상태 |
| 병원 등록 | 병원명·주소·연락처·대표 와치 관리자 계정 이메일 입력 → 자동 코드 발급 |
| 병원 상세 | 소속 의료진 목록, 시니어 현황, 기기 현황, 와치 관리자 변경 |
| 와치 관리자 배정 | 기존 계정을 병원에 배정하거나 초대 이메일 발송 |
| 병원 비활성화 | 서비스 종료 병원 비활성화 (소속 시니어 데이터 보존) |
| 병원별 현황 | 병원별 활성 기기 수·데이터 수집률·긴급 이벤트 발생 횟수 요약 |

### 3.6 PC 웹 — 운영자

> 일상 서비스 운영 담당. 계정 승인·삭제·권한 변경·병원 등록·시스템 설정 변경 **불가**.

| # | 화면명 | 주요 기능 |
|---|--------|-----------|
| O-01 | 대시보드 | 운영 현황 모니터링 — 긴급 이벤트·가입자 추이·수집률 조회 (읽기 전용) |
| O-02 | 계정 조회 | 전체 계정 목록 검색·조회 (승인·정지·삭제 버튼 없음) |
| O-03 | 공지사항 관리 | 공지 작성·수정·삭제, 대상 역할 지정, 예약 발송 |
| O-04 | 내 계정 | 프로필, 비밀번호 변경 |

> **운영자 접근 제한 요약**: 병원·기관 관리 메뉴 없음 / 권한 관리 메뉴 없음 / 시스템 설정 메뉴 없음 / 계정 승인·삭제 버튼 비활성 / 운영자 관리 메뉴 없음

## 7. UI/UX 결정 사항

### 7.1 사이드바 계층 구조 (pc-admin)

3단계 계층으로 구성한다.

```
병원·기관 관리  (nav-item, 1단계)
  └─ 운영자 관리    (nav-sub-item, 2단계)
       └─ 계정 관리   (nav-sub-sub-item, 3단계)
```

모든 pc-admin 8개 파일(dashboard, accounts, hospitals, operators, peer-averages, permissions, notice, settings)에 동일하게 적용.

### 7.2 신체 정보 필드

계정 프로필에 키(cm)·몸무게(kg)·출생년도·성별 4개 필드를 포함한다.

| 화면 | 구현 방식 |
|------|-----------|
| pc-admin/accounts.html (계정 상세 모달) | 숫자 입력(input[type=number]) + 라디오 버튼 |
| mobile/settings.html | 신체 정보 섹션 읽기 전용 표시. 성별은 값 표시 + "프로필 수정에서 변경" 안내 |
| mobile/profile-edit.html | 스텝퍼(−/+ 버튼) UI로 키·몸무게·출생년도 수정, 성별은 칩 버튼 선택 |

### 7.3 권한 관리 탭 UI

permissions.html에서 "역할별 권한 설정"과 "건강 데이터 공개 범위"를 하나의 카드 내 탭으로 통합.  
기본 탭: 역할별 권한 설정.

### 7.4 대시보드 리포트 다운로드

dashboard.html의 "리포트 다운로드" 버튼 클릭 시 요약 통계 CSV 파일을 생성하여 다운로드한다. 파일명 형식: `dashboard-report-YYYY-MM-DD.csv`
