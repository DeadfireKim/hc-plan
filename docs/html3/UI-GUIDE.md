# hc-plan v3 — UI 공통 가이드

> `docs/html3/` 정적 HTML 목업의 디자인 규칙. **새 화면 제작 시 반드시 준수.**
> 사내 `rnd_portal` 디자인을 차용(레이아웃·컴포넌트) + 색은 hc-plan 아이덴티티로 교체.
> CSS = `assets/app.css` (rnd_portal `tokens.css`+`global.css` 합본, 색 토큰만 변경).
> 폰트 Noto Sans KR · 각진 톤(radius 0, 버튼만 4px) · 컴팩트(행높이 32px).
> ⚠️ 화면 유형 코드(L/D/S 등)는 **기획·문서용** — 실제 화면(제목·LNB)에 노출하지 않는다(app.css에서 숨김). 화면 설명문도 사용설명("~클릭하면 ~") 대신 실무 부제로.

## 3. LNB

- 메뉴 항목에 화면 유형 배지(`lnb-type-badge`)

## 4. L형 (리스트) 화면 표준
- **조회조건**(`filter-bar`): 버튼 순서 **`[↺ 초기화] [조회]`** (초기화가 왼쪽)
- **툴바**(`table-toolbar`): **`총 N건 ··· [N개씩 보기] [엑셀] [추가]`**
  - 등록 버튼 라벨 = `추가` (＋기호 없음), 툴바 우측
  - ❌ 헤더(`page-header-actions`)에 등록 버튼 두지 않음
- **페이징**: **`[« 맨앞] [‹ 이전] 1 … N [› 다음] [» 마지막]`**
- 지정 컬럼(이름 등) = `cell-link` → 상세(D)로 이동

---

## 5. D형 (상세) 화면 표준
- **상단**: 읽기전용 정보 = `form-table` (라벨 우측정렬 | 값, 2열쌍)
  - **마지막 2행 = (입력일시 | 입력자) / (수정일시 | 수정자)** — 각각 별도 항목, 감사 추적(모든 상세화면 공통)
- **버튼**(`.detail-actions` — 정보 테이블 아래 중앙, 위 여백 8px): **`[수정(primary)] [위험액션(danger)] [목록(secondary)]`**
  - 라벨 "정보 수정" ❌ → **"수정"** ⭕
  - "목록"은 헤더가 아니라 이 버튼 줄에
- **하단**: 탭 + 리스트

---

## 6. 탭 (app.css 적용 완료)
- 박스형, 너비 일정(`min-width:110px`, 가운데 정렬)
- 비활성 연회색 `#eef1f4` / 활성 연틸배경 `#cfe5df` + 틸 글자 + 볼드
- 테두리 전부 회색 통일 (활성도 회색)
- 탭바 좌측 패딩 0 → 첫 탭 = 테이블 왼쪽 정렬
- 탭바 `margin-bottom: calc(-1*var(--space-3))` → 아래 테이블과 딱 붙임

---

## 7. 버튼
- 링크형 버튼(`a.btn`) 밑줄 없음 (app.css `.btn { text-decoration:none }`)
- 종류: `btn-primary`(틸) / `btn-secondary`(회색) / `btn-danger`(레드) / `btn-excel`(녹색) / `btn-text` / `btn-icon`
- 크기: `btn-md`(30px) / `btn-sm`(24px)

## 10. 날짜·시각 표기 (공통)
- **날짜(일자)**: `YYYY-MM-DD` (예: 2026-03-12) — 라벨은 "~일자"
- **일시(datetime)**: `YYYY-MM-DD HH:MM:SS` (24시간, 예: 2026-03-12 14:20:05) — 라벨은 "~일시"

## 11. 빈 데이터 표기 (공통)
- 값이 없으면 **`—` 등 placeholder 금지 → 빈 셀(공백)** 로 노출. 예: `<td class="num"></td>`
- 단, `<title>`·제목의 구분자 `—`(예: "… — 데모 허브")는 데이터가 아니므로 유지

## 12. 약어 툴팁 (Tier 등)
- Tier 배지처럼 의미를 모를 약어는 **마우스 오버 툴팁** 제공
- 공통 스크립트 `assets/tier-tip.js` 를 화면에 포함하면 `.badge`(Tier1/2/3) 에 자동으로 툴팁 부착
- 툴팁 스타일은 app.css `.tip[data-tip]` — 다른 약어도 `class="... tip" data-tip="설명"` 으로 재사용 가능

## 13. 정렬·옵션 (공통)
- **목록·select 옵션은 기본 이름 ASC(가나다순)** 정렬
- **select placeholder에 `…`(말줄임) 금지** — "의료진 선택"(⭕) / "의료진 선택…"(❌)

## 14. S형(대시보드) 카드
- 통계 카드(`stat-card`): **테두리 없음**, 카드마다 다른 파스텔 배경(`nth-child` 4색 순환 — 연틸/연앰버/연레드/연녹), 모서리 `border-radius:8px`(각진 톤 base=0의 예외) — **모든 대시보드 동일**(app.css 공통)
