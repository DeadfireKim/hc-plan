이번 주 건강 요약
이번 주 평균 건강 점수는 71점으로 전주(74점) 대비 소폭 하락했습니다. 수요일 저녁 심박수 이상과 수면 패턴 불규칙이 주요 원인으로 분석됩니다. 걸음수와 활동량은 목표의 82% 수준으로 양호합니다.
주의 사항
  • 수요일(17일) 야간 심박수 96bpm 이상이 2시간 지속
  • 금요일(19일) 수면시간 5.2시간으로 권장 미달
  • 주말 활동량 급감 (평일 대비 40% 수준)
  • SpO₂ 95% 미만 구간이 주 3회 이상 관찰됨

  • 매일 7,000보 이상 걷기 목표 유지
  • 취침 시간 23시 이전으로 조정 권장
  • 수면 무호흡 의심으로 전문의 상담 권장
