# 건강정보 서비스 : 2026.04.17

## 개요

- 사용자의 스마트밴드에서 정보를 주기적으로 수집하고,
- 이를 AI통해 분석하여 건강정보를 제공하는 서비스를 만들고자 한다.

## 구성요소

  | 구분     | 역할                                                          |
  | -------- | ------------------------------------------------------------- |
  | 모바일앱 | 스마트밴드로부터 수집된 건강정보를 수집서버로 주기적 전송     |
  | 수집서버 | RestAPI를 제공하는 서버로 정보를 DB로 축적                    |
  | 웹서비스 | 사용자, 간호사, 의사등이 접속해서 사용자의 건강정보 추적/관리 |
  
## 사용 시나리오

1. 웹서비스를 통해서 사용자 정보를 등록한다.
2. 모바일앱을 설치하고 Google Health Connect / Apple Health와 연동한다.
3. 웹서비스를 통해서 사용자 ID용 인증 QR코드를 생성하고 모바일앱 카메라로 인식한다.
4. 이제 모바일앱은 1시간단위로 건강정보를 수집서버로 전송한다.
5. 수집서버는 사용자별로 건강정보를 시간순으로 누적한다. (사용자 정보는 Uniqkey값으로 처리)
6. 웹서비스쪽에서 주기적으로 수집서버의 정보를 퍼와서 AI 기반으로 분석한다.
7. 매일 밤에 전날 사용자별 건강 정보를 통합하여 종합의견을 정리해서 웹서비스에 축적한다.

## 서비스 사용자

| 구분   | 역할                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| 사용자 | 건강정보를 제공하고 종합분석 정보를 조회하거나 추가적인 건강관련 조언을 받는다 |
| 의사   | 사용자의 건강정보중 위험/이상 등으로 분류된 종합의견을 검토 / 의견을 단다      |
| 상담사 | AI나 의사의 판단에 따른 사용자와 통화 / 이후 병원 안내 등을 수행한다           |
| 분석가 | 건강정보를 바탕으로 보다 고도화된 분석이 가능하도록 분석기법을 개선한다        |
| 관리자 | 시스템 운영에 필요한 정보를 관리하는 System Admin                              |

## 제공 서비스

- 사용자에게 일정 비용을 받거나, 무료로 등록하여 Demo 기간(임의지정)동안 정보를 수집
- 사용자별로 24시간 단위 분석 대상 시간을 설정할 수 있다. 
  - 예, 철수는 전일09 ~ 금일09시, 영희는 12부터 24시간.
- 사용자가 설정된 24시간 단위 분석 대상 기간에 대하여 AI분석을 1차로 수행한다
- 사용자별로 일 / 주 / 월단위 분석 리포트를 지속적으로 제공하고 추적관리 한다.
- AI 분석결과는 종합하여 사용자에게 알려준다 (SMS, Push, Email 등 선택 가능)
- 의사 / 상담사는 위험/이상 정보를 검토하여 사용자와 통화하고 건강상태를 체크한다
- 상담사는 문제가 있거나 의심스럽다고 생각하는 경우 병원 예약까지 대행해 줄 수 있다.
- 사용자는 웹서비스에 로그인해서 자신의 건강정보 분석결과를 조회할 수 있다.
