## 폴더 구조

```
html/
├── assets/
│   ├── css/
│   │   ├── base.css        # 리셋, CSS 변수, 타이포그래피
│   │   ├── layout.css      # 사이드바, 헤더, 콘텐츠 영역
│   │   ├── components.css  # 카드, 버튼, 테이블, 뱃지 등
│   │   └── print.css       # A4 PDF 인쇄용
│   ├── js/
│   │   ├── mock-data.js    # 전체 더미 데이터
│   │   └── charts.js       # 차트 렌더링 유틸
│   └── img/
├── common/
│   └── nav.html            # 사이드바/헤더 스니펫 (참조용)
├── user/
├── doctor/
├── counselor/
├── admin/
└── index.html              # 전체 화면 목록 네비게이션
```
